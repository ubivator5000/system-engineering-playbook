## 8. Архитектура

**Стиль архитектуры:** Event-driven микросервисная архитектура с CQRS-подходом.

**Ключевая идея:** Платёжный оркестратор, который объединяет сайт школы, Т-Банк, Битрикс24 и 1С в единый контур.

---

### Как это устроено

Система состоит из десяти контейнеров, разделённых на три логических слоя.

**Слой входа и безопасности.** API Gateway выполняет аутентификацию школ через HMAC-подпись, ограничивает частоту запросов (5 RPM с одного IP) и проверяет идемпотентность — чтобы повторные запросы от школ не создавали дублирующиеся платежи.

**Платёжное ядро (Command).** Payment Core вызывает Т-Банк, обрабатывает вебхуки и управляет рекуррентными подписками. Все запросы проходят через RabbitMQ — это буферизирует платежи, защищает систему от всплесков и делает её отказоустойчивой: при падении внешних сервисов сообщения остаются в очереди. Retry Scheduler (единственный stateful сервис с leader election) отвечает за повторные списания при отказе карты — 1, 24 и 72 часа. Notification Dispatcher отправляет уведомления менеджерам в ВК и студентам через ВК или СМС.

**Слой управления и аналитики (Query).** School Cabinet — личный кабинет школы. Здесь генерируются API-ключи, настраиваются роли (CEO, менеджер, бухгалтер, тех. администратор) и параметры retry. Analytics Engine — фоновый сервис, который слушает очередь и обновляет данные: горячие метрики (выручка за сегодня, неделю, месяц) пишет в Redis, а дневные агрегаты — в PostgreSQL. Dashboard API — лёгкий HTTP-сервис, который по запросу School Cabinet отдаёт метрики: горячие — из Redis за доли миллисекунды, исторические (квартал, год) — из агрегатных таблиц PostgreSQL.

**Хранилища.** PostgreSQL — основное хранилище данных. В нём лежат платежи, подписки, школы, API-ключи, идемпотентность, аудит-логи с SHA256-цепочкой и агрегатные таблицы (выручка по дням, по месяцам, LTV по студентам, отток). Redis — горячий кэш для текущих метрик, сессий пользователей, API-ключей и счётчиков rate limiting.

**Внешние артефакты** устанавливаются у школ. WordPress Plugin встраивает виджет оплаты через шорткод. Tilda Template добавляет PayLect в список платёжных систем Tilda. Bitrix24 App создаёт сделки и задачи при успешных платежах. 1С выгружает платежи через эндпоинт.
