### 3. Интеграции с внешними системами

#### Интеграция №1: WordPress (виджет)

| Параметр | Описание |
|----------|----------|
| Тип | Плагин для WordPress, работающий через шорткод |
| Протокол | REST API (исходящий от сайта к PayLect) + Webhook (входящий от PayLect к сайту) |
| Данные от сайта → PayLect | `amount`, `product_name`, `product_id`, `student_name`, `student_surname`, `student_patronymic`, `student_phone` |
| Данные от PayLect → сайт | Статус платежа, ссылка на оплату |
| Установка | Установка из каталога WordPress: «Плагины» → «Добавить новый» → найти «PayLect» → установить и активировать |
| Настройка | Ввести API-ключи (Public Key и Secret Key) на странице настроек плагина (ключи из личного кабинета PayLect) |
| Использование | Вставить виджет на страницу курса и в настройках в интерфейсе подвязать его к курсу |

---

#### Интеграция №2: Tilda (шаблон платежной системы)

| Параметр | Описание |
|----------|----------|
| Тип | Custom Payment Gateway (шаблон, добавляемый в публичный список Tilda) |
| Протокол | HTTP POST от Tilda к API PayLect + уведомление от PayLect на Notification URL Tilda |
| Данные от Tilda → PayLect | `amount`, `product_name`, `product_id`, `student_name`, `student_surname`, `student_patronymic`, `student_phone` |
| Данные от PayLect → Tilda | Редирект на success/fail URL + уведомление о статусе платежа |
| Установка | Выбрать PayLect из списка платежных систем в настройках Tilda, ввести API-ключ (из личного кабинета PayLect) |

---

#### Интеграция №3: Битрикс24 (приложение)

| Параметр | Описание |
|----------|----------|
| Тип | Приложение из маркетплейса Битрикс24 |
| Протокол | Webhook от PayLect к приложению, REST API Битрикс24 (исходящий от приложения) |
| Данные от PayLect → Битрикс24 | `amount`, `product_name`, `product_id`, `student_name`, `student_surname`, `student_patronymic`, `student_phone` |
| Действия в Битрикс24 | Создание сделки, обновление статуса, создание задачи менеджеру |
| Установка | Установить приложение из маркетплейса, ввести API-ключ (из личного кабинета PayLect) |

---

#### Интеграция №4: 1С:Бухгалтерия (внешняя обработка)

| Параметр | Описание |
|----------|----------|
| Тип | Внешняя обработка (файл .epf), скачиваемая из личного кабинета PayLect |
| Протокол | HTTP-запрос от обработки к API PayLect (GET /api/v1/payments) |
| Данные от PayLect → 1С | Список платежей: дата, сумма, ФИО студента, телефон студента, название курса, статус |
| Действия в 1С | Создание и проведение документов «Поступление на расчетный счет» |
| Установка | Скачать .epf из личного кабинета, открыть в 1С, ввести API-ключ, настроить один раз |
